# 后端使用指南（pnpm）

本文档用于说明当前后端项目的技术栈、运行方式与常见命令，适用于使用 pnpm 进行依赖管理的场景。

## 技术栈

- Node.js + TypeScript
- NestJS
- GraphQL (Apollo)
- TypeORM + SQLite
- pnpm 作为包管理器

> 说明：
> - `class-validator`：用于 DTO 入参校验（如 `@IsString`、`@IsOptional`、`@Min`）
> - `class-transformer`：用于请求体转换为 DTO 类实例，并进行类型转换

## 环境要求

- Node.js 16+（建议 18）
- pnpm 8+

## 安装依赖

```bash
pnpm install
```

## 启动开发环境

```bash
pnpm run start:dev
```

默认启动在 `http://localhost:3000`，GraphQL Playground 位于：

```
http://localhost:3000/graphql
```

## 数据库

默认使用MySql 5.7.44.  安装地址 https://dev.mysql.com/downloads/installer/

如果想配置sql信息，就到app.module.tsx 里面修改：

``` tsx
TypeOrmModule.forRoot({
      type: "mysql",
      host: "localhost",
      port: 3306,
      username: "root",
      password: "123456",
      database: "yisu_hotel",
      entities: [`${__dirname}/modules/**/*.entity{.ts,.js}`],
      logging: true,
      synchronize: true,
      autoLoadEntities: true,
    }),
```

若需要初始化数据，请执行 `xiecheng/xiecheng-server/data/` 下的 SQL 脚本，我已经生成一些数据。

- H5 搜索接口：`searchHotels`
- H5 详情接口：`hotelDetail`
- H5 Banner：`homeConfig`

如需扩展接口或新增字段，请优先更新 GraphQL schema 和 DTO。
