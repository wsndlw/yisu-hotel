# 移动端接口使用指南（H5 / GraphQL / Apollo / Hooks）

> 本文档对应仓库根目录的 `src/` 目录（示例移动端接口层）。
>
> - GraphQL 语句：`src/graphql/*-h5.ts`
> - Hooks 封装：`src/services/*-h5.ts`
> - TypeScript 类型：`src/types/*.ts`

---

## 1. 依赖安装

```bash
pnpm add @apollo/client graphql
# 或
npm i @apollo/client graphql
```

---

## 2. Apollo Client 初始化

`src/utils/apollo.ts` 已提供最简 client（默认 `http://localhost:3000/graphql`）。

```ts
import { client } from './utils/apollo';
```

入口处包裹 `ApolloProvider`：

```tsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import { ApolloProvider } from '@apollo/client';
import { client } from './utils/apollo';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <ApolloProvider client={client}>
    <App />
  </ApolloProvider>,
);
```

---

## 3. 通用返回结构

多数移动端接口返回：

```ts
{
  code: number; // 业务状态码，200 为成功
  message: string; // 错误或提示信息
  data: T; // 业务数据体
}
```

Hooks 会：
- `code !== 200` 时抛出 `Error`
- 成功时返回 `data`、`loading` 等

## 4. 接口与 Hooks

### 4.1 Banner 列表

- GraphQL：`src/graphql/banner-h5.ts` -> `GET_BANNERS`
- Hook：`src/services/banner-h5.ts` -> `useBanners()`

**输出**

```ts
Banner[]
// Banner
// {
//   id: string; // Banner ID
//   imageUrl: string; // 图片地址
//   redirectHotelId?: string | null; // 跳转酒店 ID（可选）
// }
```

---

### 4.2 首页配置（城市/设施）

- GraphQL：`src/graphql/hotel-h5.ts` -> `GET_HOME_CONFIG`
- Hook：`src/services/hotel-h5.ts` -> `useHomeConfig()` / `useHomeConfigV2()`

**输出**

```ts
{
  banners: { id: string; imageUrl: string; redirectHotelId?: string | null }[]; // Banner 列表
  cities: { code: string; name: string }[]; // 热门城市列表
  facilities: { id: string; name: string }[]; // 设施列表（免费 WiFi、早餐等）
}
```

---

### 4.3 POI 列表（poiList）

- GraphQL：`src/graphql/hotel-h5.ts` -> `POI_LIST`
- Hook：`src/services/hotel-h5.ts` -> `usePoiList()`

**输入**：`PoiListInput`

```ts
{
  city: string;        // 必填：城市编码
  keyword?: string;    // 可选：关键词（名称/地址）
  limit?: number;      // 可选：最大数量，默认 50
  type?: string;       // 可选：类型过滤（shopping/spot/subway/food/medical 等）
}
```

**输出**：`PoiItem[]`

```ts
[
  {
    id: string;                 // POI ID
    name: string;               // POI 名称
    type: string;               // POI 类型
    address?: string | null;    // 地址
    latitude?: number | null;   // 纬度
    longitude?: number | null;  // 经度
    baseScore?: number | null;  // 热度评分
    city: string;               // 城市编码
  }
]
```

---

### 4.4 酒店最低价日历（hotelMinPriceCalendar）

- GraphQL：`src/graphql/hotel-h5.ts` -> `HOTEL_MIN_PRICE_CALENDAR`
- Hook：`src/services/hotel-h5.ts` -> `useHotelMinPriceCalendar()`

**输入**：`HotelMinPriceCalendarInput`

```ts
{
  hotelId: string;    // 必填：酒店 ID
  startDate?: string; // 可选：开始日期（YYYY-MM-DD），不传默认今天
  endDate?: string;   // 可选：结束日期（YYYY-MM-DD），不传默认 30 天范围
}
```

**输出**：`HotelMinPriceCalendar`

```ts
{
  hotelId: string; // 酒店 ID
  days: Array<{
    date: string;  // 日期（YYYY-MM-DD）
    price: number; // 最低价（单位：分）
  }>;
}
```

### 4.5 酒店搜索（searchHotels）

- GraphQL：`src/graphql/hotel-h5.ts` -> `SEARCH_HOTELS`
- Hook：`src/services/hotel-h5.ts` -> `useHotelSearch()`

**输入**：`SearchHotelInput`

```ts
{
  cityCode: string;              // 必填：城市编码
  checkIn: string;               // 必填：入住日期（YYYY-MM-DD）
  checkOut: string;              // 必填：离店日期（YYYY-MM-DD）
  keyword?: string;              // 可选：关键词（酒店名/地址）
  priceMin?: number;             // 可选：最低价
  priceMax?: number;             // 可选：最高价
  starRating?: number;           // 可选：星级
  sort?: 'DEFAULT' | 'DISTANCE_ASC' | 'PRICE_ASC' | 'SCORE_DESC'; // 可选：排序方式
  facilityIds?: string[];        // 可选：设施过滤
  latitude?: number;             // 可选：用户纬度（用于距离筛选/排序）/也可以是某个地标的经度，如夫子庙
  longitude?: number;            // 可选：用户经度（用于距离筛选/排序）/也可以是某个地标的纬度，如夫子庙
  distanceMax?: number;          // 可选：最大距离（公里）
  poiId?: string;                // 可选：POI ID（单选）
  bedType?: string;              // 可选：床型枚举（KING/TWIN/FAMILY/SUITE）
  guestCount?: number;           // 可选：入住人数
  pagination?: {
    page: number;                // 必填：页码（从 1 开始）
    pageSize: number;            // 必填：每页数量
  };
}
```

**输出**：`HotelConnection`

```ts
{
  items: Hotel[];  // 酒店列表
  minPrice: number; // 当前列表最低价
  total: number; // 总数量
  page: { total: number; pageNum: number; pageSize: number }; // 分页信息
}

// Hotel
// {
//   id: string;                      // 酒店 ID
//   hotelNo?: string | null;         // 酒店编号
//   name: string;                    // 酒店名称
//   coverImage?: string | null;      // 封面图
//   favoriteCount?: number | null;    // 收藏数 （随机数，移动端展示用）
//   score?: number | null;           // 评分 （随机数，移动端展示用）
//   minPrice?: number | null;        // 最低价
//   distance?: number | null;        // 距离（米）
//   distanceText?: string | null;    // 距离文本（1千米以上：1.2km，1千米以下：580米 ）
//   address?: string | null;         // 地址
//   latitude?: string | null;        // 纬度
//   longitude?: string | null;       // 经度
//   roomType?: RoomType[] | null;    // 房型
// }
//
// RoomType
// {
//   id: string;                      // 房型 ID
//   name: string;                    // 房型名称
//   bedType?: string | null;         // 床型枚举
//   basePrice?: number | null;       // 基础价格
//   maxGuests?: number | null;       // 最大入住人数
//   hasBreakfast?: boolean | null;   // 是否含早
//   refundable?: boolean | null;     // 是否可退
//   hasWindow?: boolean | null;      // 是否有窗
//   area?: number | null;            // 面积
//   floor?: string | null;           // 楼层
//   isOnSale?: boolean | null;       // 是否上架
//   sortOrder?: number | null;       // 排序
//   stock?: number | null;           // 库存
//   images?: string | null;          // 图片 JSON （url）
// }
```

### 4.6 酒店详情（hotelDetail）

- GraphQL：`src/graphql/hotel-h5.ts` -> `GET_HOTEL_DETAIL`
- Hook：`src/services/hotel-h5.ts` -> `useHotelDetail()`

**输入**

```ts
{
  id: string;          // 必填：酒店 ID
  checkIn?: string;    // 可选：入住日期（YYYY-MM-DD）
  checkOut?: string;   // 可选：离店日期（YYYY-MM-DD）
}
```

**输出**：`HotelDetail`

```ts
{
  id: string;                 // 酒店 ID
  name: string;               // 酒店名称
  address?: string | null;    // 地址
  description?: string | null; // 介绍 
  favoriteCount?: number | null; // 收藏数
  images: string[];           // 图片列表
  facilities: string[];       // 设施列表
  nearbyPoi?: Array<{
    id: string;               // POI ID
    name: string;             // 名称
    type: string;             // 类型
    address?: string | null;  // 地址
    latitude?: number | null; // 纬度
    longitude?: number | null; // 经度
    distanceKm?: number | null; // 距离（公里）
    baseScore?: number | null;  // 热度评分
    city: string;             // 城市编码
  }> | null;
  rooms: Array<{
    id: string;               // 房型 ID
    title: string;            // 房型名称
    coverImage?: string | null; // 封面图
    hasBreakfast?: boolean | null; // 是否含早
    refundable?: boolean | null; // 是否可退
    area?: number | null;     // 面积
    hasWindow?: boolean | null; // 是否有窗
    price: number;            // 价格（单位：分）
    stock?: number | null;    // 库存
    bedType?: string | null;  // 床型
  }>;
}
```

## 5. 使用示例（Hooks）

```ts
import { useHotelSearch, useHotelDetail, usePoiList, useRoomTypeCalendar } from './services/hotel-h5';

const { data: hotels } = useHotelSearch({
  cityCode: '320100',
  checkIn: '2025-01-01',
  checkOut: '2025-01-02',
  pagination: { page: 1, pageSize: 10 },
});

const { data: hotel } = useHotelDetail('hotel-id');

const { data: pois } = usePoiList({ city: '320100', keyword: '夫子庙' });

const { data: calendar } = useRoomTypeCalendar({
  roomTypeId: 'room-type-id',
  startDate: '2025-01-01',
  endDate: '2025-01-07',
});
```
