## 2. Apollo Client 初始化与全局包裹

### 2.1 Apollo Client 放在哪里？

本仓库已提供最简 client：`src/utils/apollo.ts`（默认指向 `http://localhost:3000/graphql`）。

```ts
import { client } from './utils/apollo';
```

你可以按需要在这里扩展：
- token 注入（Authorization）
- error link（登录失效、统一提示等）
- 更细的 cache 策略

### 2.2 React 项目里必须包裹 ApolloProvider

只要使用了 `useQuery/useLazyQuery/useMutation` 等 hooks，就必须在 React 入口处包一层 `ApolloProvider`。

示例（`main.tsx` / `App.tsx` 入口）：

```tsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import { ApolloProvider } from '@apollo/client';
import { client } from './utils/apollo';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <ApolloProvider client={client}>
    <App />
  </ApolloProvider>,
);
```

常见报错：
- `Could not find "client" in the context`：说明没包 `ApolloProvider` 或者包裹层级不对。

## 3. 接口返回结构约定（一定要看）

后端接口大致分两类：

### 3.1 Result 包装（推荐）

多数移动端接口返回：

```ts
{
  code: number;
  message: string;
  data: T;
}
```

Hooks 内部会做两件事：
- 如果 `code !== 200`，将其转换为 `Error` 透出（`error` 字段）
- 如果成功，则把 `data` 提出来返回

### 3.2 直接返回数据（无 Result 包装）

例如 `bannersQuery` 返回的就是 `Banner[]`。

这种情况下：
- 业务错误一般会体现在 GraphQL error，Apollo 会把它放在 `error` 里
- hooks 内只做字段映射和兜底，不再判断 `code`

## 4. 首页（Home）接口

### 4.1 Banner（推荐走 bannersQuery）

- GraphQL：`src/graphql/banner-h5.ts` -> `GET_BANNERS`
- Hook：`src/services/banner-h5.ts` -> `useBanners()`

说明：
- Banner 的 `enabled + startAt/endAt` 时间窗口过滤 **已在后端完成**
- 前端 hook 内做字段统一：把后端的 `targetHotelId` 映射为 `redirectHotelId`

用法示例：

```tsx
import { useBanners } from '../services/banner-h5';

export function HomeBanner() {
  const { banners, loading, error, refetch } = useBanners();

  if (loading) return <div>加载中...</div>;
  if (error) return <div>{error.message}</div>;

  return (
    <div>
      <button onClick={() => refetch()}>刷新</button>
      {banners.map((b) => (
        <img
          key={b.id}
          src={b.imageUrl}
          alt=""
          style={{ width: '100%', display: 'block' }}
          onClick={() => {
            // 点击跳转到酒店详情页
            // navigate(`/hotel/${b.redirectHotelId}`)
          }}
        />
      ))}
    </div>
  );
}
```

### 4.2 首页基础配置（cities/tags）

- GraphQL：`src/graphql/hotel-h5.ts` -> `GET_HOME_CONFIG`
- Hook：`src/services/hotel-h5.ts` -> `useHomeConfig()`

说明：
- 后端 `homeConfig` 也会返回 banners，但在当前后端实现下 **不保证**按 `startAt/endAt` 做过滤
- 因此不建议直接使用 `homeConfig.data.banners` 用于轮播图展示

用法示例：

```tsx
import { useHomeConfig } from '../services/hotel-h5';

export function HomeFilters() {
  const { data, loading, error } = useHomeConfig();

  if (loading) return null;
  if (error) return <div>{error.message}</div>;

  return (
    <div>
      <div>城市：{data?.cities?.map((c) => c.name).join('、')}</div>
      <div>标签：{data?.tags?.map((t) => t.name).join('、')}</div>
    </div>
  );
}
```

### 4.3 首页推荐组合：useHomeConfigV2（推荐）

- Hook：`src/services/hotel-h5.ts` -> `useHomeConfigV2()`

它会：
- cities/tags 走 `homeConfig`
- banners 走 `bannersQuery`
- 最终对外返回一份合并后的 `data`，调用方更省事

```tsx
import { useHomeConfigV2 } from '../services/hotel-h5';

export function HomePage() {
  const { data, loading, error, refetch } = useHomeConfigV2();

  if (loading) return <div>加载中...</div>;
  if (error) return <div>{error.message}</div>;

  return (
    <div>
      <button onClick={() => refetch()}>刷新</button>
      <div>轮播图数量：{data?.banners?.length || 0}</div>
      <div>城市数量：{data?.cities?.length || 0}</div>
      <div>标签数量：{data?.tags?.length || 0}</div>
    </div>
  );
}
```

## 5. 酒店搜索与详情

### 5.1 酒店搜索（高频）：useHotelSearch

- GraphQL：`src/graphql/hotel-h5.ts` -> `SEARCH_HOTELS`
- Hook：`src/services/hotel-h5.ts` -> `useHotelSearch()`

特点：
- 使用 `useLazyQuery`，只有你调用 `search(input)` 时才会真正发请求
- 默认 `network-only`，适合列表价格实时变化场景

```tsx
import { useEffect } from 'react';
import { useHotelSearch } from '../services/hotel-h5';

export function HotelListPage() {
  const { search, data, loading, error } = useHotelSearch();

  useEffect(() => {
    search({ pageNum: 1, pageSize: 10, keyword: '杭州' });
  }, [search]);

  if (loading) return <div>加载中...</div>;
  if (error) return <div>{error.message}</div>;

  return (
    <div>
      {(data?.items || []).map((h) => (
        <div key={h.id}>{h.name}</div>
      ))}
    </div>
  );
}
```

### 5.2 酒店详情：useHotelDetail

- GraphQL：`src/graphql/hotel-h5.ts` -> `GET_HOTEL_DETAIL`
- Hook：`src/services/hotel-h5.ts` -> `useHotelDetail(id)`

```tsx
import { useParams } from 'react-router-dom';
import { useHotelDetail } from '../services/hotel-h5';

export function HotelDetailPage() {
  const { id } = useParams();
  const { data, loading, error, refetch } = useHotelDetail(id);

  if (loading) return <div>加载中...</div>;
  if (error) return <div>{error.message}</div>;

  return (
    <div>
      <h1>{data?.name}</h1>
      <button onClick={() => refetch()}>刷新</button>
      {(data?.rooms || []).map((r) => (
        <div key={r.id}>{r.title}</div>
      ))}
    </div>
  );
}
```

## 6. 设施与标签（筛选项）

这部分已经是 hooks 写法，无需额外改造：

- `src/services/facility-h5.ts`
  - `useFacilitiesForH5()`
  - `useTagsForH5()`

用法：

```tsx
import { useFacilitiesForH5, useTagsForH5 } from '../services/facility-h5';

export function Filters() {
  const { facilitiesByCategory, loading: fLoading } = useFacilitiesForH5();
  const { tagsByCategory, loading: tLoading } = useTagsForH5();

  if (fLoading || tLoading) return null;

  return (
    <div>
      <pre>{JSON.stringify({ facilitiesByCategory, tagsByCategory }, null, 2)}</pre>
    </div>
  );
}
```

## 7. 常见问题

### 7.1 为什么 hooks 里要做“业务错误”处理？

因为后端很多接口用了 Result 包装（`code/message/data`）。

Apollo 的 `error` 只能捕获“网络层/GraphQL 层”错误，捕获不到 `code !== 200` 这种业务错误。
所以在 hooks 内部统一把 `code !== 200` 转成 `Error` 透出，页面用起来会更一致。

### 7.2 缓存策略怎么选？

- 列表/首页（价格、投放变化较快）：`network-only`
- 设施/标签（变化不频繁）：`cache-first`
