# ADR-0006：容器化模块单体并与 Node.js 并行替换

- 状态：Proposed（技术基线候选，待独立评审）
- 日期：2026-10-07

## 背景

本轮不正式发布，但交付物必须达到可上线标准，并保留 Node.js 回滚路径。

## 决策

交付非 root、多阶段构建的 Python Docker 镜像，配套 Compose 开发依赖和 Nginx/API 网关示例。dev/test/staging/prod 使用相同镜像、不同外部配置。

Node.js 在 P9 前保留。影子阶段只复制读请求；写接口在隔离数据库比对。未来切流使用 Python 小流量、指标对比和网关快速回切，禁止两个服务同时对同一业务写流量。

## 后果

- 环境一致且保留快速回滚能力。
- P2 必须提供 liveness/readiness、结构化日志和配置启动校验。
- P11 必须完成迁移失败、健康检查失败和回滚 Runbook，但不实际连接生产服务器。
