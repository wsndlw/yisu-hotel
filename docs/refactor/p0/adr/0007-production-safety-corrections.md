# ADR-0007：安全与数据正确性修正优先于缺陷兼容

- 状态：Proposed（技术基线候选，待独立评审）
- 日期：2026-10-07

## 背景

现有实现包含公开管理员注册、默认 JWT 密钥、硬编码数据库凭据、自动同步表结构、明文验证码/日志、缺少幂等键和不完整状态校验。复制这些行为会阻碍生产使用。

## 决策

兼容目标是合法业务契约，不是安全漏洞和数据正确性缺陷。`scope.md` 列出的批准修正可改变现有错误行为，但必须：

1. 在 P1 基线报告中记录旧行为；
2. 有明确错误语义和自动化测试；
3. 若影响前端处理，提供兼容说明；
4. 在 P9 差异报告中标记为“ADR-0007 已批准”，而非隐藏差异。

## 后果

- 未批准契约差异仍必须为 0。
- 安全改动不会因“旧服务就是如此”而被阻止。
- 每项修正都需要可追踪证据，不能借安全名义扩大功能范围。
