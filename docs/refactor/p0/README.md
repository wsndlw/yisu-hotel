## 1. P0 结论

本轮采用以下冻结基线：

- 以 Python 3.12、FastAPI、Ariadne、SQLAlchemy 2 和 Alembic 建设模块化单体。
- 保留 `/graphql`、现有 GraphQL Schema、JWT Bearer 认证方式和 MySQL 数据标识。
- 数据库目标运行版本为 MySQL 8.0；现有 MySQL 5.7 数据作为迁移来源兼容，不在本轮更换数据库类型。
- Node.js 服务保留为契约基线和回滚路径；Python 服务完成 P9 验收前不承接生产写流量。
- 当前已有的订单、设施、Banner、POI、审核记录、日历价格/库存和外部集成均纳入一期迁移。
- 真实支付、退款、发票、优惠券、客服、UI 大改和正式生产发布延期，不进入本轮。
- Node.js 改为 Python 是对原 PDF 服务端技术要求的有意偏离；业务验收范围不因此缩减。
- 公开注册 `ADMIN` 的行为不作为兼容契约，生产环境必须移除；这是批准的安全修正。

1. 与实际环境隔离的 MySQL 克隆实例（最适合核对结构、索引、字符集和数据量）。
